# Dukaan-Dashboard

## 📖 Introduction

Re-creating the dukaan dashboard to refresh my React and TailwindCss skills.


## 🛠️ Technologies Used

- **React.js** – Component-based UI development

- **JavaScript** – Core scripting language

- **Tailwind CSS** – Utility-first styling framework

## 🚀 Live Demo
🔗 [View Dukaan-Dashboard](https://dukaan.amithbv.com/)

## 📦 Setting Up the Project Locally

Clone the repository and navigate into the project :

```bash
git clone https://github.com/AmithBV0606/Dukaan-Dashboard.git
cd Dukaan-Dashboard
```

## Install Dependencies 

Ensure you have Node.js (>=16.0.0) and npm or yarn installed.

```bash
npm install  # or yarn install
```

## ▶️ Running the Project

Using Docker (Recommended)

```bash
docker compose up
```

Running Locally without Docker

```bash
npm run dev  # or yarn dev
```
